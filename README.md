# Are Ireland's Small Enterprises at Risk?
The project uses storytelling through data visualisation to uncover patterns in Ireland's small business landscape, explore changes in enterprise survival and communicate what the data reveals about the challenges facing small enterprises.

## Project Overview
An exploratory analysis of Irish small enterprise demography, examining enterprise births, deaths and survival trends between 2015 and 2020 using data from the Central Statistics Office (CSO).

## Project Objectives
- Examine trends in small enterprise births and deaths.
- Investigate enterprise survival patterns.
- Explore changes in small business demography over time.
- Communicate findings through interactive Tableau visualisations.

## Data Source
Central Statistics Office (CSO), Business Demography, NACE Rev. 2 (2015–2020).

## Tools & Techniques
- Tableau
- Data Exploration
- Business Demography Analysis
- Data Visualisation
- Exploratory Data Analysis

## Project Deliverables
- Interactive Tableau dashboard.
- Business data visualisations.
- Analysis of enterprise births, deaths and survival trends.

## Collaboration
Collaborative academic project involving hands-on participation across the analytical process, from data exploration and analysis to visualisation and presentation.
